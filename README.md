# سید حسین جلیلی حسن کیاده

وب‌سایت شخصی با React و Vite روی [hosseinjalili.com](https://hosseinjalili.com).

## نوشتن

از [مدیریت نوشته‌ها](https://hosseinjalili.com/write/) به Pages CMS بروید و با GitHub وارد شوید. در اولین ورود، برنامه را برای همین مخزن فعال کنید. در بخش نوشته‌ها یک مورد اضافه کنید، عنوان و متن را بنویسید و ذخیره کنید. برای ویرایش نوشته‌های قبلی عنوان آن‌ها را باز کنید. در فیلد «تصویر جلد» می‌توانید عکس بارگذاری کنید تا در فهرست بلاگ و صفحهٔ نوشته نمایش داده شود. برای انتشار نسخهٔ انگلیسیِ همان نوشته، «عنوان انگلیسی» و «متن انگلیسی» را هم پر کنید. تا وقتی هر دو فیلد تکمیل نشده باشند، نسخهٔ انگلیسی سایت متن فارسی را نمایش می‌دهد. ویرایشگر تغییرات را در `content/journal.json` ثبت می‌کند. GitHub Pages با انتشار شاخهٔ master نسخهٔ تازه را در دسترس قرار می‌دهد.

## توسعه

با Node.js 24 دستورهای زیر را اجرا کنید.

```sh
npm ci
npm run dev
```

`npm run build` خروجی React و صفحه‌های HTML را در `dist` تولید می‌کند و فایل‌های قابل انتشار را در ریشهٔ مخزن می‌گذارد. پس از تغییر کد، خروجی ساخت را همراه تغییرات روی master ثبت کنید. برای بررسی خروجی می‌توان از `npm run preview` استفاده کرد. برای تغییر محتوای بلاگ، سایت داده‌های فعلی را مستقیماً از فایل عمومی ویرایشگر می‌خواند. نقشهٔ سایت و خوراک Atom هنگام ساخت تولید می‌شوند.
